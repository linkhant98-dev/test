# **App Name**: Cheesy Bites Inventory Control & BOM Variance System

## Core Features:

- Secure Access & Role Management: User authentication via Firebase, secure role-based access control, and user/role administration for managing system permissions.
- Master Data & BOM Management: Comprehensive CRUD for raw materials, finished goods, warehouses, and waste reasons. Includes multi-version Bill of Materials (BOM) management with effectivity dates and cost simulation capabilities.
- Inventory & Stock Transactions: Module for Goods Receipts, Issues to Production, Returns, Adjustments, and Transfers, ensuring accurate, real-time stock balances and average cost tracking.
- Production Order Workflow: Full production order lifecycle management from planning against a specific BOM version to capturing actual raw material consumption and output quantities, with historical data integrity.
- Automated Variance & Costing Logic: Server-side calculations for quantity variance, cost variance, waste percentage, and yield percentage, alongside automated finished good cost roll-up and threshold-based flagging for deviations.
- Interactive Dashboard & Reports: Centralized dashboard displaying key performance indicators, summary cards, and dynamic charts. A dedicated reports center with filtering and export capabilities for detailed operational insights.
- AI-Powered Variance Insight Tool: A generative AI tool that analyzes production order variances to detect anomalies and provide concise, actionable insights or highlight critical deviations for further investigation, helping identify root causes faster.

## Style Guidelines:

- The color scheme is inspired by cheese, blending a vibrant golden yellow (#FFD700) as the primary color to evoke a 'cheesy' feel with data-driven efficiency. The background color is a very light, warm off-white (#F7F4F0), providing a clean, spacious canvas for data readability. A deep olive green accent (#4F7736) is used for emphasis, creating a harmonious and grounded palette suitable for an administrative system.
- Headlines utilize 'Space Grotesk' (sans-serif), lending a modern, tech-informed, and precise feel to titles and key information. Body text, especially for data-dense tables and detailed reports, uses 'Inter' (sans-serif) for its high readability, objective clarity, and consistent presentation across various data types.
- Use a consistent set of vector-based icons that are clean, intuitive, and modern. Icons should clearly represent system actions, navigation points, status indicators, and data categories without adding visual clutter.
- A professional admin dashboard layout with a fixed, clean navigation sidebar on the left and a dynamic content area. Key modules will feature summary cards, modern tabular data displays with robust filtering, and tabbed interfaces for detailed screens. The design will be responsive for seamless viewing and interaction across desktop and tablet devices.
- Incorporate subtle, tasteful animations for user feedback and state changes, such as loading indicators, success/error notifications, and smooth transitions between UI elements to enhance the user experience without distraction.
